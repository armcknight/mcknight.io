{%- comment -%} The dots come straight from _data/, so adding a place to the data adds it to the globe. Every kind shares one array, with a `kind` telling them apart, and each entry has an id the list uses to point at it: the kind and the record's own id, since ids are unique only within a kind. A flag, rather than forloop.last, puts the commas in: the array is written by several loops, and only the very last entry of the last one must have none. A place names its regions by key and nothing more. The names, countries and continents those keys stand for are in region-data, once, rather than copied into every place. {%- endcomment -%}
